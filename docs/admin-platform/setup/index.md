# Setup

The **Setup** section contains the tools you use to design and configure an experience **before** it is delivered to learners. While Deliver is about running a live program, Setup is your authoring environment — where you define the structure, upload media, schedule events, and configure experience-level settings.

All Setup tools apply to the **currently selected experience**. Check the experience name in the top bar before making changes.

## What Setup covers

| Section | Route | Purpose |
|---------|-------|---------|
| **Designer** | `/design` | Build the experience structure — milestones, activities, tasks |
| **Calendar** | `/schedule` | Plan events: workshops, coaching sessions, deadlines |
| **Media Library** | `/design?tab=media` | Upload and organise files used across the experience |
| **Settings** | `/settings` | Notifications, branding, guides, and experience configuration |

!!! note "Experience must be selected"
    Setup sidebar items are active only when you have selected an experience context. If items appear greyed out, open **Institution Menu → Experiences** and select the program you want to configure.

## Typical workflow

Most coordinators follow a similar order when preparing a new program:

1. **Designer** — outline milestones, add activities, assessments, topics, and events.
2. **Media Library** — upload images, PDFs, and documents referenced in task instructions.
3. **Calendar** — schedule live sessions, site visits, and key deadlines.
4. **Settings** — review notification rules and experience options before going live.

!!! tip "Design before you enrol"
    Complete your core structure in the Designer before bulk-enrolling learners. It is easier to refine lock/hide rules and role visibility when there are no live participants yet.

## Sub-section guides

### [Designer](designer.md)

The Experience Designer is your main authoring canvas. Use the **Structure** tab to build the hierarchy (Experience → Milestones → Activities → Tasks) and the **Media** tab to manage files. Drag-and-drop reordering, lock/hide controls, and role targeting enable adaptive learning pathways.

### [Calendar](calendar.md)

The Calendar lets you create and manage events in list, month, week, or day views. Record attendance, run scheduling polls, and export the schedule as CSV or `.ical`.

### [Media Library](media-library.md)

Store images, documents, and video links in one place. Uploads use resumable TUS protocol so interrupted connections can resume automatically. Files are available when editing topics and events through the FilePicker.

### Settings

Experience **Settings** control notifications, defaults, and program-level options. Access from the Setup sidebar or the top navigation. For institution-wide branding, use **Institution Menu → Settings** instead.

!!! warning "Settings vs institution settings"
    **Setup → Settings** applies to one experience. **Institution Menu → Settings** applies to all programs at your institution. Changing institution branding does not affect experience-specific notification preferences.

## Who can use Setup?

| Role | Access |
|------|--------|
| **Coordinator** | Full access: Designer, Calendar, Media, and Settings |
| **Institution admin** | Same as coordinator, plus institution library and audit |
| **Reviewer / Learner** | No access — use the Practera App |

If you cannot see **Design** or **Calendar** in the sidebar, ask your institution administrator to confirm your role includes authoring permissions.
