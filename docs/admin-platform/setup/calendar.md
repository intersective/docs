# Calendar

The Calendar lets you plan and manage events for your experience — workshops, coaching sessions, site visits, deadlines, and milestones. Attendees receive notifications and can add events to their personal calendar.

Navigate to **Calendar** in the left sidebar (route `/schedule`).

![Screenshot](../../assets/placeholder.png)

---

## Calendar views

Four views are available, toggled from the tab bar at the top:

| View | Best for |
|------|---------|
| **List** | Chronological agenda — scan upcoming events at a glance |
| **Month** | High-level calendar overview for the full program period |
| **Week** | Detailed view of a specific week |
| **Day** | Single-day schedule with time slots |

Click the left/right arrows to navigate between periods. Click **Today** to return to the current date.

---

## Creating an event

1. Click **+ New Event** (or click a day/time slot in Month or Week view).
2. Fill in the event details:

| Field | Description |
|-------|-------------|
| **Title** | Name of the event |
| **Event type** | Workshop, Webinar, Coaching, Site Visit, Deadline, Milestone Check-in |
| **Date and time** | Start date/time and duration |
| **Location** | Physical address or video conference link |
| **Description** | Agenda, preparation notes, or context for attendees |
| **Linked activity** | Optionally link to an activity in the Designer |

3. Click **Save Event**.

Enrolled participants with the relevant role receive an event notification.

---

## Viewing event details

Click any event in the calendar to open its **Detail Panel**. From here you can:

- Edit the event (pencil icon)
- Delete the event (trash icon)
- Access the **Attendance** tab
- Access the **Comms** tab for event-specific communications

---

## Attendance tracking

The Attendance tab inside an event's detail panel lets you mark each attendee's presence.

1. Open the event detail panel.
2. Click the **Attendance** tab.
3. For each participant, click the status toggle: **Present**, **Absent**, or **Excused**.
4. Attendance is saved automatically.

Attendance data is available in the Progress and Reports screens.

---

## Scheduling polls

When the best time for an event is uncertain, use a scheduling poll to let participants vote on their preferred slot.

1. Open an event detail panel (or create a new event).
2. Click **Scheduling Poll** → **Create Poll**.
3. Add two or more proposed time slots.
4. Click **Send Poll** — all enrolled participants receive a notification to vote.
5. View responses in the poll panel — a summary shows the most popular slot.
6. Click **Confirm Slot** to update the event with the chosen time.

---

## Exporting the calendar

Click **Export** in the calendar toolbar:

- **CSV** — a spreadsheet of all events with date, title, type, and location.
- **iCal (.ics)** — import into Google Calendar, Outlook, or Apple Calendar.

!!! tip
    Share the iCal link with learners so they can subscribe to the experience schedule in their personal calendar app. The URL updates automatically when events change.
