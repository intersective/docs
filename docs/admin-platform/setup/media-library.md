# Media Library

The Media Library stores all files for your experience — images, PDFs, documents, and video links. Files uploaded here are available wherever you need to add media: topic instructions, event descriptions, assessment briefs, and reports.

Navigate to **Design** → **Media tab** (route `/design?tab=media`), or access it via **Institution → Library → Media** for institution-wide files.

![Screenshot](../../assets/placeholder.png)

---

## Two media libraries

Practera has two levels of media storage:

| Library | Scope | Location |
|---------|-------|----------|
| **Experience media** | Files for a single experience | Design → Media tab |
| **Institution media** | Shared files available across all experiences | Institution → Library → Media |

Use experience media for content specific to this program. Use institution media for shared assets like your brand logo, common templates, or reusable PDFs.

---

## Browsing the library

Files are displayed in a **grid view** (thumbnails) or **list view** (table with metadata). Toggle between views using the icons in the top right.

Each file card or row shows:

- **Thumbnail** (images) or type icon (PDF, DOCX, etc.)
- **File name**
- **File size**
- **Upload date**
- **File type**

### Searching and filtering

- Type in the **search box** to filter by file name.
- Use the **type filter** dropdown to show only images, PDFs, or documents.

## Uploading files

### Drag and drop

Drag files from your computer directly onto the media grid. A drop zone appears highlighting valid upload targets.

### Upload button

1. Click **Upload** in the toolbar.
2. Select one or more files in the file picker.
3. The upload progress appears in a toast notification at the bottom.

### Resumable uploads

Uploads use the **TUS protocol** — if your connection drops mid-upload, the upload resumes automatically when connectivity returns. You do not need to re-upload the file from scratch.

### File constraints

| Constraint | Limit |
|------------|-------|
| Maximum file size | 10 MB |
| Supported image formats | JPEG, PNG, WebP, GIF |
| Supported document formats | PDF, DOCX, XLSX, PPTX |
| Video | Links only (YouTube, Vimeo, Kaltura) — not direct upload |

!!! note "Large files"
    For files larger than 10 MB, contact support@practera.com. We can configure an increased limit for your institution.

## Managing files

### Rename a file

Click the **pencil icon** on a file card (or right-click → Rename). Type the new name and press **Enter**.

### Delete a file

Click the **trash icon** on a file card → confirm deletion.

!!! warning "Deletion affects references"
    Deleting a file removes it from the library **and** from any activities that reference it. Learners who have already downloaded the file will retain their copy, but the link in the activity instructions will break. Check file usage before deleting.

### Check file usage

Click the **ⓘ icon** on a file card to see which activities, tasks, or sections reference this file. This helps you assess the impact of renaming or deleting.

---

## Using the FilePicker

When editing a topic, event, or report section, click **Insert Media** or the attachment icon to open the **FilePicker** modal. This lets you browse and select files from the media library without leaving the editor.

The FilePicker shows both experience media and institution media, so you can use shared brand assets alongside experience-specific files.
