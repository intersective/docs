# Expert Tools

The **Expert** section provides advanced automation and AI tools for experienced coordinators. Use these tools to build adaptive learning pathways, reward achievement, and configure intelligent support for your learners.

---

## What Expert covers

| Tool | Route | Purpose |
|------|-------|---------|
| **Triggers** | `/automation` | Automated workflows that fire when conditions are met |
| **Badges** | `/automation?tab=badges` | Digital achievement awards for learners |
| **AI Experts** | Institution → Library → AI Experts | Custom AI assistant configurations |

!!! tip "Start with Triggers"
    Triggers are the most powerful tool for creating adaptive experiences. Even simple unlock rules (e.g. "unlock Activity B when learner completes Activity A") significantly improve learner engagement.

---

## Triggers

Triggers are event-driven automation rules. When a specified event occurs (e.g. a learner submits an assessment, earns a badge, or a due date passes), Practera automatically takes a configured action (e.g. unlock a new activity, send a notification, award a badge).

See [Triggers & Badges](triggers.md) for the full guide.

---

## Badges

Badges are digital achievements that motivate learners and celebrate progress. They appear in the learner's profile and can be shared externally. Badges can be awarded automatically via a trigger, or manually by a coordinator.

See [Triggers & Badges](triggers.md) for the full guide.

---

## AI Experts

AI Experts are custom-configured AI assistants that learners can chat with during the experience. Each expert has a name, avatar, and a system prompt that defines its personality, knowledge domain, and guidance style.

Configure AI Experts at the institution level: **Institution → Library → AI Experts**.

Common use cases:

- **Industry mentor persona** — an AI that plays the role of a senior professional in the learner's industry
- **Research assistant** — an AI that helps learners find and evaluate sources
- **Reflective coach** — an AI that asks Socratic questions to deepen learning

!!! note
    AI Expert responses are generated by the configured language model (GPT-4o or Claude). Set up your AI API key under **Institution → Settings → Integrations → AI API Keys** to use your organisation's quota.
