# Practera Admin Platform

The **Practera Admin Platform** is the unified administration interface for running experiential learning programs. It brings together everything coordinators, institution administrators, and Practera CS managers need to design experiences, enrol participants, deliver programs, and measure outcomes — all from one place.

Whether you are setting up a new internship program, reviewing learner submissions, or checking institution-wide analytics, the Admin Platform is your home base for program management.

---

## Who is it for?

The Admin Platform is designed for people who **manage** programs rather than participate in them:

| Role | Typical responsibilities |
|------|-------------------------|
| **Coordinator** | Day-to-day delivery — feedback, teams, comms, reports |
| **Institution administrator** | Institution settings, user management, branding, audit |
| **Author** | Experience design, assessments, scheduling |
| **CS manager** (Practera staff) | Cross-institution support, billing, super badges |

Learners and reviewers use the **Practera App** instead — a separate interface optimised for completing activities and giving feedback.

## What's new in v2.6

Version 2.6 introduces a modern admin experience while preserving everything you already know how to do.

### Modern admin shell

The Admin Platform now runs inside a **React-based shell** that wraps the existing Practera tools. You get a cleaner layout, faster navigation, and a consistent look across new and legacy screens.

### Unified navigation

The sidebar is organised into three clear sections:

- **Deliver** — run your program day to day (dashboard, feedback, reports)
- **Setup** — configure your experience (design, calendar, users, settings)
- **Expert** — advanced tools (triggers, AI experts)

### New and improved features

| Feature | What it does |
|---------|--------------|
| **Real-time feedback pipeline hub** | See submissions flowing in and manage review queues at a glance |
| **Teams kanban board** | Visualise team formation and progress across columns |
| **Reports builder** | Create custom reports without leaving the admin interface |
| **Skills growth metrics** | Track how learners develop skills over the course of a program |
| **Comms / chat** | Message learners and experts with real-time conversation threads |

!!! tip "Legacy screens"
    Some screens are still transitioning to the new interface. If you see a legacy screen, it works the same way as before — the underlying features have not changed, only the surrounding navigation may look different.

### Dashboard

Your program command centre — enrolment stats, activity health, and quick actions for the experience you are managing.

### Experiences

Browse, select, and switch between experiences at your institution. See status, learner counts, and go-live controls.

### Institutions

Institution-wide settings for administrators — branding, audit logs, billing (CS admins), and the experience library.

### Users & Enrolments

Add coordinators, enrol learners and experts, manage teams, and handle bulk CSV uploads.

### Deliver

Day-to-day program delivery — feedback queues, progress tracking, comms, teams kanban, and report cards.

### Setup

Experience configuration — the designer, calendar and due dates, user roles, and experience settings.

### Expert Tools

Advanced capabilities — adaptive triggers, badge rules, and AI expert agents embedded in your experience.
