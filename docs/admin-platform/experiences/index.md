# Experiences

The **Experiences** page lists every learning program at your institution in one searchable, filterable view. From here you can switch into a program, review its status, and perform common management actions without navigating through multiple menus.

![Screenshot](../../assets/placeholder.png)

---

## Opening the Experiences list

You can reach the Experiences list in two ways:

1. Click your **institution badge** in the top bar, then select **Experiences** from the institution menu
2. Navigate directly to **Experiences** if it appears in your sidebar (institution-level context)

Each experience is shown as a **card** in a grid layout. Cards are designed to give you the essential information at a glance before you click into a program.

---

## What's on each card

Every experience card displays:

| Element | Description |
|---------|-------------|
| **Name** | The program title as learners and coordinators see it |
| **Status badge** | Current lifecycle state — **Live**, **Draft**, or **Inactive** |
| **Enrolled learners** | Count of participants currently enrolled |
| **Description** | Short summary of the program (if one has been set in Settings) |

Click a card to **select** that experience. The top bar updates to show the experience name and status, and the sidebar switches to experience-level tools (Dashboard, Feedback, Designer, and so on).

### Status badges explained

| Badge | Meaning |
|-------|---------|
| **Live** | The experience is published; enrolled learners can access it |
| **Draft** | The experience is being designed or tested; learners cannot access it yet |
| **Inactive** | The experience is no longer active but data is retained |

See [Going Live](go-live.md) for the full workflow from Draft to Live.

---

## Searching and filtering

Use the controls at the top of the page to find experiences quickly:

- **Search** — type part of an experience name to narrow the grid in real time
- **Status filter** — show **All**, **Live**, **Draft**, or **Inactive** experiences only

!!! tip "Filter before you search"
    If your institution runs many programs, set the status filter to **Live** first, then search by name. This is the fastest way to find an active cohort during a busy delivery period.

---

## Actions on each card

Each experience card includes a menu of management actions. Available options may depend on your role.

| Action | What it does |
|--------|--------------|
| **Settings** | Opens experience settings (name, branding, notifications, integrations) |
| **Duplicate** | Creates a copy of the experience structure — useful as a template for a new cohort |
| **Export JSON** | Downloads a JSON file of the experience design for backup or migration |
| **Archive** | Moves the experience out of the active list while preserving all data |
| **Delete** | Permanently removes the experience (requires confirmation) |

!!! warning "Delete is permanent"
    Deleting an experience removes its design and associated data. Use **Archive** when a program has finished running unless you are certain the data is no longer needed. Deletion cannot be undone without contacting Practera support.

Archive and Delete actions prompt you to **confirm** before proceeding. Read the confirmation message carefully — it summarises what will happen to learner data.

## Creating a new experience

To start a new program:

1. Click the **+** button on the Experiences page, **or**
2. Select **New Experience** from the header (when available in institution view)

You will be guided through creating a blank experience or choosing a template from the **Experience Library**. After creation, the new experience opens in **Draft** status so you can design content before going live.

!!! note "New experiences start as Draft"
    Learners cannot see a Draft experience. Complete your design, configure enrolments and notifications, then use [Going Live](go-live.md) when you are ready to publish.

---

## Common workflows

### Starting a new cohort from an existing program

1. Find the previous cohort on the Experiences list
2. Choose **Duplicate** from the card menu
3. Rename the copy in **Settings → General**
4. Update enrolments and due dates in Setup
5. Go live when ready

### Finding an experience you manage but did not create

Use **Search** by name or filter by **Live** status. If you still cannot see an experience, your institution administrator may need to grant you access or assign you as a coordinator.
