# Comms & Chat

The Comms screen provides communication tools for coordinators to stay in touch with experience participants. Use it to send direct messages, broadcast announcements, schedule automated communications, and configure notification rules.

Navigate to **Comms** in the left sidebar (route `/comms`).

![Screenshot](../../assets/placeholder.png)

---

## Three tabs

| Tab | Purpose |
|-----|---------|
| **Chat** | Real-time messaging — channels, threads, scheduled messages |
| **Email** | Send one-off emails to participants or roles |
| **Notifications** | Configure automated notification rules |

---

## Chat tab

The Chat tab has a two-panel layout:

- **Left panel** — channel list with search
- **Right panel** — selected channel's message thread

### Channel types

| Type | Who is in it | Best for |
|------|-------------|---------|
| **Direct** | Two people | 1-to-1 conversations |
| **Group** | Multiple selected users | Small team check-ins |
| **Broadcast** | Coordinator → all participants | Announcements to the whole cohort |
| **Team** | All members of a specific team | Team coordination (created automatically when teams are set up) |

### Creating a channel

1. Click the **+** icon in the channel list header.
2. Select the channel type.
3. Name the channel.
4. Add members from the participant list.
5. Click **Create**.

### Sending a message

1. Click the channel in the left panel to open it.
2. Type your message in the text box at the bottom.
3. Use the formatting toolbar for **bold**, *italic*, links, and bullet lists.
4. Press **Enter** or click **Send**.

### Scheduled messages

Schedule a message to be sent at a future date/time — useful for sending reminders, deadline notices, or milestone kick-off messages in advance.

1. Compose your message in the text box.
2. Click the **calendar icon** (next to the Send button).
3. Select the date and time.
4. Click **Schedule**.

Scheduled messages appear in the **Scheduled** tab within the channel view. You can edit or cancel them before they are sent.

!!! tip
    Use scheduled messages to automate milestone reminder sequences. Schedule a "Week 3 milestone is opening tomorrow" message at the start of the experience, then let it fire automatically.

## Notifications tab

The Notifications tab lets you control which automated emails and push notifications Practera sends to participants.

### Notification categories

| Category | Description |
|----------|-------------|
| **Submission reminders** | Remind learners when an assessment due date is approaching |
| **Review reminders** | Remind reviewers when they have pending reviews |
| **Feedback acknowledgement** | Notify learners when a review is ready to read |
| **Enrolment welcome** | Welcome email when a user is enrolled |
| **Event reminders** | Remind participants before calendar events |
| **Badge awarded** | Notify learners when they earn a badge |

Toggle each category on or off. Some categories have additional settings (e.g. how many days before the due date to send a submission reminder).
