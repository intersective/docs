# Institutions

The **Institutions** screen provides a cross-institution view of every organisation registered on the Practera platform. It is used by Practera **Customer Success (CS) administrators** to monitor account health, open institution detail pages, and create new institutions.

![Screenshot](../../assets/placeholder.png)

---

## Who can access this screen?

The Institutions list is **only visible to CS administrators** — Practera staff with the Customer Success role. Institution coordinators and local administrators manage their own institution through the **Institution menu** in the top bar; they do not see this global list.

!!! note "Looking for your own institution settings?"
    If you are a coordinator or institution administrator, open your **institution badge** in the top bar and choose **Settings**, **Users**, or **Experiences**. You do not need the CS Institutions screen for day-to-day program delivery.

---

## What the list shows

The Institutions page displays a table of all registered institutions. Each row summarises:

| Column | Description |
|--------|-------------|
| **Name** | Institution display name |
| **Active experiences** | Number of experiences currently in Live status |
| **Learner count** | Total learners enrolled across all experiences at the institution |
| **Status** | Account status (for example, Active, Trial, Suspended) |

The table is sorted for quick scanning — use **Search** to find a specific institution by name when the list is long.

---

## Searching institutions

Type in the **Search** box at the top of the page to filter rows by institution name. Search matches from the start of the name and updates the table as you type.

!!! tip "Search by partial name"
    You do not need the full institution name — a few characters from the university or organisation name is usually enough to narrow the list.

---

## Opening institution detail

Click any **row** in the table to open the **Institution detail** page for that organisation. The detail view provides tabs for Overview, Experiences, Users, Library, Reporting, and Settings — everything CS admins need to support an account.

See [Institution Overview and Tabs](overview.md) for a full tour of each tab.

---

## Creating a new institution

To register a new organisation on the platform:

1. Open the **Institutions** list (CS admin only)
2. Click **Create new institution** (or the **+** button, depending on your layout)
3. Enter the required details — institution name, initial administrator email, and region/stack assignment
4. Save to provision the institution

After creation, the new institution appears in the list. The designated administrator receives onboarding instructions to log in, configure branding, and create their first experience.

!!! warning "Institution creation affects billing and data isolation"
    Each institution is a separate tenant — learner data, experiences, and settings do not cross institutions. Confirm contract and billing details before creating production institutions.

## Common CS workflows

| Task | Starting point |
|------|----------------|
| Check account health before a QBR | Institutions list → sort by learner count → open Overview tab |
| Investigate a support ticket | Search institution name → open detail → Users or Experiences tab |
| Provision a new customer | Create new institution → confirm admin received login → guide through [Branding](branding.md) |
| Review GDPR deletion history | Institution detail → Experiences → **Data Deletion Records** sub-tab |
