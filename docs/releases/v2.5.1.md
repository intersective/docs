# Release v2.5.1
📅 Release Date: 2026-08-20

## Highlights
- **H5P Simulations**: Educators can now upload `.h5p` packages directly in the experience designer. Learners play them inside the app, and completion is automatically recorded — no browser plugin required.
- **Institution Admins Can Edit Live Assessments**: With a new per-institution flag, institution administrators can now edit assessments that already have submissions, a capability previously restricted to Practera CS staff only.
- **Experience Structure Diagram (Pebble)**: A new interactive visual diagram of any experience's milestone → activity → task structure is available in the designer, including a PowerPoint export for sharing with stakeholders.
- **Peer Review Fairness Fix**: The peer review assignment algorithm now guarantees every team member receives a reviewer, replacing the previous first-come-first-served approach.
- **Auto-Remove Dropped Students from Teams**: When a student's enrolment status is set to `dropped`, they are automatically removed from all teams and any pending peer reviews assigned to them are cancelled.
- **Advisor Digest Email**: Mentors and coordinators now receive a single daily digest of outstanding review tasks rather than one email per overdue review.

## ✨ New Features

### H5P Simulations
- **H5P Package Upload in Designer**: The Simulations task type is now fully enabled in the activity designer. Educators can upload any `.h5p` file; the platform extracts the package to S3 automatically.
- **Learner Simulation Player**: The learner app now embeds an H5P player inside the activity task view. All standard H5P content types are supported.
- **Automatic Progress Tracking via xAPI**: When a learner completes a simulation, the H5P player dispatches an xAPI `completed` event that the app converts into a Practera task-completion record — no manual marking required.
- **Background H5P Unpack Service**: A new background Lambda worker unpacks uploaded `.h5p` zips from S3 and organises them into a content/libraries structure, keeping shared libraries deduplicated.

### Experience Designer
- **Experience Structure Diagram (Pebble Diagram)**: A new "Structure Diagram" button in the designer toolbar opens a full-screen, interactive visual map of the experience. Milestones, activities, and tasks are rendered as colour-coded, draggable cards.
- **Learner / Expert View Toggle**: The diagram can be filtered to show only what learners see, or only what experts see, helping coordinators verify visibility settings at a glance.
- **PowerPoint Export**: The structure diagram can be exported as a `.pptx` file, generating an overview slide plus individual drill-down slides per milestone — ready for stakeholder presentations.
- **Inline Editing in Diagram**: Milestone and activity titles and descriptions can be edited directly in the diagram, with autosave. Changes are reflected immediately without leaving the designer.
- **Event Task Type Activated**: Events (scheduled sessions, workshops) are now a fully supported task type in the designer, including location, capacity, duration, and a built-in scheduling popup.

### Institution Admin Capabilities
- **Edit Live Assessments (Per-Institution Flag)**: A new `allow_edit_assessments_with_submissions` institution flag (toggled by CS admins) allows institution admins to edit assessment questions and choices even after submissions exist.
- **Feature Flag Management UI**: CS admins now have toggles for `allow_edit_assessments_with_submissions` and `chat_enable` directly in the institution settings editor.

### Communication & Notifications
- **Advisor Digest Email**: Instead of individual overdue-review nudges, mentors and coordinators now receive one consolidated daily email listing all outstanding reviews across their assigned teams.
- **`[assessment_name]` in ELSA Reminders**: ELSA (automated nudge) review reminder templates now support the `[assessment_name]` variable, letting coordinators write more specific reminder messages.

### Learner App
- **File Row Click to Preview**: Clicking anywhere on a file row in assessments and reviews now opens a preview (PDF, images) or triggers a download (other types), rather than requiring a dedicated icon tap.
- **In-App File Preview**: PDF and image files now open in a full-screen preview modal inside the app. Office documents open via an external viewer link.
- **Team Roster Card**: A new team roster view shows all members of the learner's current team, including names, roles, and avatars.
- **Reviewer Name Display**: While a submission is under review, learners now see "Your submission is being reviewed by [Name]" instead of a generic waiting message.
- **Admin Console Button**: Coordinators and admins now have an "Admin Console" button in the settings page that generates a one-click link to the corresponding admin interface — no separate login required.

### Reporting (Cutie)
- **Feedback-Not-Given Matrix**: A new report page shows a matrix of which reviewers have not yet submitted feedback for which learners, making it easy to chase outstanding reviews.
- **"My Teams Only" Toggle on Progress Table**: Coordinators and mentors can now toggle the progress table to show only the learners in their assigned teams, reducing noise in large cohorts.

### Enrolment Management
- **Student Tagging**: Institution and experience admins can now apply tags (e.g. cohort, school, state) to individual enrolments for grouping and filtering purposes.
- **Auto-Remove Dropped Students**: Setting a student's status to `dropped` automatically removes them from all team memberships and cancels any peer reviews where they were the assigned reviewer.

### Multi-Expert Collaboration
- **Mentors Can Review Multiple Teams**: Mentors assigned to more than one team can now submit feedback for each team independently on team-scoped moderated assessments.
- **All Team Mentors Can View Deliverables**: For team-scoped moderated assessments, all mentors and coordinators assigned to that team can view submitted deliverables, not just the primary reviewer.
- **Multi-Team Member Selector**: When a mentor is assigned to multiple teams, the Team Member Selector assessment question now lists members from all their assigned teams in a single picker.

### Browser Tab Isolation
- **Per-Tab Experience Context**: Opening Practera in multiple browser tabs no longer causes tabs to interfere with each other's active experience. Each tab now maintains its own session context independently.

## 🐞 Bug Fixes

- **Team 360 Submit Guard Restored**: The confirmation prompt that warns learners when they attempt to submit a Team 360 assessment without visiting all pages has been restored.
- **Chat Disable Respected**: Setting `chat_enable = false` on an experience or institution now correctly disables the chat feature in the learner app. The previous code treated any falsy value as `true`.
- **Hyperlinks Default to HTTPS**: The TinyMCE and Summernote editors in the activity designer now automatically prepend `https://` to links that don't include a protocol, preventing broken or HTTP-only links.
- **Overdue Review Threshold Fixed**: Reviews are now only marked overdue after the assessment's due date plus a 24-hour grace period. The previous logic used a fixed 2-day window from assignment date, producing false positives.
- **Peer Review Fairness**: The round-robin peer review assignment now ensures every team member receives exactly one reviewer. Previously, the algorithm could leave some members without any assigned reviewer.
- **Nameless Duplicate Milestones**: Fixed a bug in the Pebble diagram where adding or deleting milestones and activities would produce ghost/duplicate entries in the designer due to incorrect DOM manipulation.

## 🔐 Security

- All security improvements from v2.5.0 are included in this release.

## 📌 Other Improvements

- **Enrolment Tags API**: The GraphQL API now supports reading and writing enrolment tags, enabling future filter and export use cases.
- **GraphQL Integration Tests**: New integration test coverage for `chatEnable`, `updateEnrolmentStatus`, `myTeamMembers`, and `reviewerFeedbackStatus` resolvers.
- **PHPUnit Tests**: Added PHPUnit tests for `Institution.getFlag`, `AppController._institutionFlag`, and the enrolment team-removal `afterSave` hook.
- **Unit Tests for New App Components**: The H5P player, team roster, and reviewer name display all have unit test coverage.
