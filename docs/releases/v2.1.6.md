# Release v2.1.6

📅 Release Date: 2023-06-16

- **Enhanced Badge Awarding for Learners**: Resolved issues with badge awarding, ensuring learners receive recognition for their achievements promptly.

- **Badge Earning Failure for Learners**: Fixed logic errors preventing badge awards, enhancing motivation and engagement.
