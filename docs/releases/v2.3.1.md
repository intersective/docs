# Release v2.3.1

📅 Release Date: 2024-02-26

## Highlights
- **WYSIWYG Editor for Admins and Educators**: Admins and Educators can now select and use a WYSIWYG editor for enhanced content editing within the App.
- **Improved Admin Interface Reliability**: Resolved critical issues in the Admin Interface, including JSON import loops and user invite failures, ensuring seamless operations.
- **Enhanced Assessment Feedback for Reviewers**: Reviewers can now submit feedback on all question types, improving the assessment workflow in the AppV3.
- **GraphQL API Enhancements**: New and improved GraphQL API endpoints for certificate customisation and template management, enhancing flexibility for Admin users.

## ✨ New Features

- **WYSIWYG Editor Integration**: Admins and Educators can now select a preferred WYSIWYG editor for editing topic content, enhancing content creation capabilities within the App.
- **GraphQL API for Certificate Customisation**: A new API allows Admins to issue certificates with custom names, providing greater personalization options.
- **GraphQL API for Template Updates**: Admins can now update template visibility efficiently using the new `updateTemplate` mutation, improving template management.
- **GraphQL Query for User Badges**: Learners and Educators can retrieve all badges earned within their institution, offering a comprehensive view of achievements.

## 🔧 Enhancements

- **CUTIE Template Visibility Toggle**: Admins can now easily switch templates between public and private states with a new toggle button, enhancing control over template distribution.
- **App Activity Screen Visual Update**: The activity screen now features a lead image as the backdrop, improving visual engagement for all users.
- **CUTIE Angular/Ionic Version Update**: Upgraded frameworks enhance app performance, security, and compatibility, benefiting all users.

## 🐞 Bug Fixes

- **Admin Interface Import and Invite Fixes**: Resolved issues with JSON import loops and user invite failures, ensuring reliable Admin Interface operations.
- **Assessment Feedback Submission**: Fixed submission failures for submitter-only questions, allowing Reviewers to provide comprehensive feedback.
- **Admin Interface Export and Data Privacy**: Corrected errors in team export downloads and audit log data exposure, enhancing data integrity and privacy.
- **GraphQL API Template Query Fixes**: Addressed issues with template queries, ensuring accurate retrieval of both public and private templates for Admins.
- **Email Notification Link Corrections**: Fixed broken and outdated links in various email notifications, improving communication reliability for Admin users.

## 🔐 Security

- **Audit Log Data Privacy**: Enhanced security by correcting permissions misconfigurations in audit logs, ensuring institution-specific data access for Admins.

## 📌 Other Improvements

- **GraphQL API Performance**: Improved filtering logic for template queries, enhancing data retrieval efficiency for Admin users.
- **App Page Title Consistency**: Resolved title display issues across the App, improving navigation clarity for all users.
