# Release v2.5.2
📅 Release Date: 2026-08-20

## Highlights
- **Team Todo Tasks**: A new collaborative task type lets coordinators define a shared todo list for each team. Team members claim items, set due dates, mark completions, and give each other praise — replacing ad-hoc spreadsheet tracking with a structured, in-platform workflow.
- **GraphQL-Native Designer**: The experience designer now talks exclusively to the GraphQL API. All milestone, activity, task, assessment, topic, and event operations are driven by GraphQL mutations, removing the last PHP AJAX endpoints from the design flow and paving the way for a future Next.js rebuild.
- **Coordinator Todo Health Dashboard**: A new dashboard widget gives coordinators an at-a-glance view of each team's todo health — flagging unassigned items, overdue tasks, skewed workloads, and frequent take-over patterns.

## ✨ New Features

### Team Todo Tasks
- **New Task Type in the Designer**: "Team Todo" is a new task type available in the experience designer (enabled per-institution via the `todo_tasks_enabled` flag). Coordinators drag it into an activity like any other task type.
- **Todo Group Editor**: An inline editor in the designer lets coordinators define the group title, description, estimated total hours, and whether team members may add their own items.
- **Pre-defined Todo Items**: Coordinators add a list of items directly in the designer. Items can be reordered by drag-and-drop and deleted or edited at any time before learners start.
- **Team Member Actions**: Inside the learner app, team members can:
  - **Claim** an unassigned item (take it on)
  - **Take over** an item already assigned to a teammate (with confirmation)
  - **Mark complete** their claimed item
  - **Praise** a completed item from any team member
  - **Add their own items** (if the coordinator enables `allowMemberAdditions`)
- **Progress Bar**: Each team's todo task shows a live progress bar (completed / total) so members can see the team's collective progress at a glance.
- **Overdue Indicators**: Items with a due date in the past are highlighted with an overdue badge.
- **Assignment History**: Every claim and take-over is recorded in an append-only audit trail per item.
- **Praise is Idempotent**: Each member can praise a completed item once; duplicate praise attempts are silently ignored.

### Coordinator Analytics
- **Todo Health Widget**: A new "Team Todo Health" widget on the Cutie coordinator dashboard shows all todo groups in the current experience. For each group it displays:
  - Completion percentage with a progress bar
  - Counts for completed, assigned, unassigned, and overdue items
  - Warning flags: unassigned items, overdue items, skewed workload (one member carrying significantly more than others), and frequent take-over patterns

### GraphQL-Native Experience Designer
- **All Designer Operations via GraphQL**: Every interaction in the experience designer — creating and reordering milestones, activities, and tasks; editing assessments, topics, and events; managing assessment groups, questions, and choices; setting achievement triggers — now calls a GraphQL mutation directly from the browser. PHP AJAX endpoints are no longer used for designer operations.
- **Centralised `DesignerAPI` Module**: A new client-side `DesignerAPI` module consolidates all GraphQL calls from the designer JavaScript, making the codebase easier to maintain and straightforward to port to a future Next.js interface.
- **New GraphQL Mutations** (available to all experiences, not just Todo):
  - Reorder milestones, activities, tasks, assessment groups, questions, and choices
  - Move tasks between activities and activities between milestones
  - Full assessment group and choice CRUD
  - Extended topic editing (video link, file attachments, TTS audio delete)
  - Event CRUD with scheduling (create, update, soft-delete)
  - Set and clear achievement unlock/reveal triggers on milestones, activities, and tasks
  - `createAndAddTask` — atomic task creation + activity sequence insertion in a single mutation
- **New GraphQL Queries**:
  - `designProject` — full project tree (milestones → activities → tasks) for the designer
  - `assessmentEditor` — complete assessment structure (groups, questions, choices) for the assessment editor
  - `searchAchievements` — achievement autocomplete for trigger assignment
  - `previewMagicLink` — generate a role-based preview link without leaving the designer

### Institution Feature Flags
- **`todo_tasks_enabled`**: New per-institution flag (off by default). When enabled, the Team Todo block appears in the designer task palette and all Todo-related GraphQL mutations are permitted. Toggle available in the institution settings editor.

## 🐞 Bug Fixes

- **Todo Task Not Appearing in Designer Palette**: The Team Todo block was not shown in the task palette when `todo_tasks_enabled` was false. The flag gate is now applied at render time, not just at mutation time.
- **Take-over History Not Recorded**: The assignment history array was not being updated when a take-over occurred in some edge cases where the previous assignment history was stored as a JSON string rather than a parsed array. Both formats are now handled consistently.

## 📌 Other Improvements

- **`project_todo_groups` and `project_todo_items` Tables**: New database tables store the todo task data separately from the legacy `core_todo_items` table, with no risk of data conflicts.
- **Learner App Task Routing**: The activity service now maps `type: 'todo'` tasks to the new `TodoTaskComponent`. Desktop and mobile routing are both handled.
- **GraphQL Integration Tests**: New integration test coverage for `createTodoGroup`, `updateTodoGroup`, `createTodoGroupItem`, `claimTodoItem`, `takeOverTodoItem`, `completeTodoItem`, `praiseTodoItem`, `reorderTodoGroupItems`, `softDeleteTodoGroupItem`, and `getTodoGroupAnalytics`.
- **Test Suite Targets**: Four new test targets have been added to the DevOps Center TUI — designer integration, todo integration, designer regression, and todo regression — runnable from the test runner screen.
