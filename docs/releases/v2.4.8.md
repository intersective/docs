# Release v2.4.8
📅 Release Date: 2026-04-01

## Highlights
- **Enhanced Assessment Navigation**: Educators and Learners can now navigate large sets of assessment questions more efficiently with the introduction of pagination functionality.
- **Improved Chat Functionality for Admins**: The chat interface for Admin users has been fixed, resolving the blank screen issue and ensuring seamless communication.
- **Flexible Assessment Design**: Admin users can now add slider questions to assessments, enhancing the flexibility of assessment configurations.
- **Timely Access to Activities**: Learners will experience improved access to activities as the unlocking mechanism now functions correctly after conditions are met.

## ✨ New Features

- **Customised Report Generation**: Admin users can now generate customised reports based on selected metrics, enhancing reporting flexibility and functionality.

## 🔧 Enhancements

- **File Upload System Upgrade**: The file upload functionality has been upgraded to replace the existing Filestack integration with the Uppy file upload system, providing improved performance and user experience.
  
- **Pagination Component Visibility Improvements**: The page numbers in the pagination component have been enlarged for better visibility, and the navigation buttons have been repositioned for enhanced accessibility.

- **Metric Report Section Reordering**: Admin users can now reorder sections of metric reports using a drag-and-drop interface, improving usability and report customisation.

## 🐞 Bug Fixes

- **Chat Screen Rendering Issue**: Resolved a bug that caused the chat screen to appear blank for Admin users, ensuring proper functionality of the chat feature.

- **Assessment Question Display Fix**: Corrected an issue where only the first eight questions were displayed under completed reviews, allowing Educators and Reviewers to see all relevant questions.

- **Locked Activities Unlocking Issue**: Fixed the problem where locked activities did not unlock after Learners met the necessary conditions, ensuring timely access to activities.

- **File Upload Indicator Reset**: Resolved an issue where the file upload indicator did not clear after a file was uploaded, enhancing the user experience during assessments.

- **"Mark As Complete" Button Functionality**: Fixed the issue where the "Mark As Complete And Continue" button was disabled incorrectly, facilitating smoother navigation for Reviewers.

## 🔐 Security

- **XSS Vulnerability Mitigation**: Updated the application to ensure that all data bindings are properly sanitised, preventing potential cross-site scripting (XSS) vulnerabilities.

## 📌 Other Improvements

- **API Testing for New Reports Feature**: Comprehensive API tests have been created for the newly introduced reports feature, ensuring functionality, performance, and security.

- **Confirmation Modal for Report Deletion**: A confirmation modal has been added to the report deletion process, reducing the risk of accidental deletions and maintaining data integrity.
