# Release v2.5.0
📅 Release Date: 2026-08-20

## Highlights
- **New Login Experience**: A fully rebuilt authentication flow brings passwordless login via magic link and passkey (biometric/hardware key), LTI 1.3 deep linking for LMS platforms, and institution-branded login pages.
- **Security Hardening**: Significant security improvements across the entire platform, including stronger transport security, tightened cross-origin policies, and enforced secure session handling.
- **Performance Improvements**: Internal service upgrades and dependency updates reduce response times and improve reliability across the Admin, App, and API layers.

## 🔐 Security

- **Strengthened Platform-Wide Security Headers**: Content Security Policy, HTTP Strict Transport Security, Cross-Origin headers, and related protections have been tightened across all Practera services, reducing exposure to common web vulnerabilities.
- **Enforced Secure Session Cookies**: Session cookies are now always marked secure, regardless of environment configuration.
- **API Access Restrictions**: All API surfaces now only accept requests from verified Practera domains, limiting the potential for unauthorised cross-origin access.

## 🚀 New Features

- **Passwordless Login**: Users can now sign in via a one-time email code (magic link) or a registered passkey (biometric or hardware security key), removing the need for passwords entirely.
- **Stack Switching**: Users with access to multiple Practera environments can switch between them seamlessly after a single sign-in.
- **LTI 1.3 Deep Linking**: Instructors using Canvas, Moodle, Blackboard, and other LMS platforms can now deep-link directly to specific Practera activities, with full LTI 1.3 Advantage support.
- **Passkey MFA for Admin LTI Launches**: Administrators with a registered passkey must complete biometric verification during LTI launch, providing a mandatory second authentication factor.
- **Institution-Branded Login Page**: The login page now displays your institution's logo and colours, delivering a consistent white-labelled experience from first click.

## 🔧 Enhancements

- **Performance Improvements**: Backend service dependencies have been updated and internal data flows streamlined, resulting in faster page loads and more reliable API responses across the platform.

## 🐞 Bug Fixes

- Various stability and compatibility fixes across the Admin interface, learner App, and API layer, addressing issues reported by customers and identified during internal testing.
