# Release v2.4.7.2
📅 Release Date: 2026-02-25

## Highlights
- **Enhanced Security for Learners**: Improved authentication logic now prevents dropped registered learners from accessing the app, ensuring a secure environment for all users.
- **Improved AI Functionality for Admins**: Resolved issues with AI audio and translation generation, enhancing the reliability of these features for Admin users.
- **Streamlined Feedback Experience**: Fixed the feedback helpfulness popup to only display when enabled, improving the user experience for Learners and Educators.
- **Accurate Due Date Management**: Standardised date format handling prevents unexpected reversion of due dates, allowing Admin users to save events accurately.

## ✨ New Features

- **Enhanced Video Attachment Preview**: Users can now seamlessly preview video attachments within topic tasks, as compatibility with all supported formats has been ensured.

## 🔧 Enhancements

- **AI Feedback Logic Update**: The feedback generation logic has been refined to ensure that AI feedback is only provided for answered text questions, improving the accuracy of feedback for Learners.
- **Search Field Prepopulation Improvement**: The account search field now correctly prepopulates when selecting a submitter's name from the Admin Feedback screen, enhancing navigation efficiency for Admin users.
- **Pulse Check Visibility Adjustment**: The visibility of the Pulse check "traffic lights" feature has been modified to only display for users in a team, reducing confusion for individual users.

## 🐞 Bug Fixes

- **Login Issue for Dropped Registered Learners**: Resolved a critical bug that allowed dropped registered learners to log in, enhancing platform security.

- **AI Experts Duplication Fix**: Addressed the issue where AI Experts were not carried over in duplicate experiences, improving usability for Admin users managing experience duplication.
- **Video Attachment Preview Modal Error**: Resolved an error message issue in the video attachment preview modal, allowing for a smoother experience for Learners and Educators.

## 🔐 Security

- **Authentication Logic Enhancement**: Updated the authentication middleware to enforce stricter checks on user registration status, significantly improving platform security for all user roles.

## 📌 Other Improvements

- **Assessment Description Formatting Fix**: Resolved a critical bug affecting the formatting of assessment descriptions, ensuring that rich text formatting is preserved after saving, which is vital for Admin users managing content.
