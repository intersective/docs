# Release v2.6.0
📅 Release Date: 2026-09-15

## Highlights
- **Modern Admin Interface (practera-admin-app)**: The Practera admin platform has been rebuilt as a React/Vite application with a unified shell — consistent navigation, real-time institution branding, and seamless transitions — while progressively migrating screens away from the legacy CakePHP interface.
- **Feedback Pipeline Hub**: A dedicated Feedback screen consolidates the submission table, reviewer assignment, feedback status matrix, and Team 360 publication into one tabbed hub.
- **Skills Growth & Metrics Dashboard**: The new Progress screen gives coordinators configurable KPI metric tiles and a skills-growth line chart showing cohort skill development over time.
- **Reports Builder**: A drag-and-drop report builder lets coordinators compose custom learner progress reports with charts, metric tiles, and formatted text sections — and publish them per learner.
- **Teams Kanban Board**: Drag-and-drop team management with auto-assignment algorithms (balanced or random distribution).
- **SpecGuard Workspace Graph**: SpecGuard extended with workspace-level contract graph, impact analysis (`specguard impact`), and cross-repo drift detection (`specguard workspace drift`).

## ✨ New Features

### Modern Admin Interface (practera-admin-app)
- **New React/Vite frontend**: A new `practera-admin-app` service (served at `admin.practera.local` in development, `admin.practera.com` in production) provides a modern, responsive admin shell built with React 19, Vite 8, Tailwind CSS v4, and Apollo Client v4.
- **Unified navigation**: Collapsible left sidebar with three sections — **Deliver** (Dashboard, Feedback, Reports), **Setup** (Design, Calendar, Users, Settings), and **Expert** (Triggers, AI Experts). Top bar shows institution branding, experience context, and quick access to user and institution menus.
- **JWT-based auth**: Tokens are passed from the login app via `?token=JWT` at the root URL, stored in localStorage, and injected as the `apikey` header on all GraphQL requests. Auth is resolved synchronously on boot — no loading flash.
- **Legacy iframe integration**: CakePHP screens not yet migrated to React are embedded transparently via an iframe with `?iframe=1`. The legacy chrome (header/sidebar) is hidden automatically, giving a seamless experience.
- **Institution branding**: The admin top bar reflects the current institution's primary colour (border + shadow) and institution name, updated dynamically via the GraphQL API.
- **Experience context**: When inside a specific experience, the top bar shows the experience name, status pill (Draft / Live / Archived), and a Go Live button.

### Feedback Pipeline Hub
- **Unified Feedback screen** (`/feedback`): three tabs — Pipeline (submission table + reviewer assignment drawer), Feedback Status (reviewer × learner matrix), Team 360 (peer review publication).
- **Submission Drawer**: click any submission to open a side drawer with full submission content, assigned reviewers, and review quality.
- **Reviewer Assignment**: assign or reassign reviewers directly from the drawer; supports multiple reviewers per submission.
- **Pipeline Summary widget**: header row showing pending, overdue, and complete counts at a glance.
- **Team 360 publication**: publish team peer review reports to learners with a single click from the Team 360 tab.

### Skills Growth & Metrics
- **Progress screen** (`/progress`): configurable KPI metric cards + skills growth line chart.
- **Skills Growth chart**: shows cohort-level skill development over time; drill down to individual skills.
- **Metric cards**: create custom metrics (engagement, completion rate, assessment scores) displayed as KPI tiles.
- **Export**: download metric data as CSV or XLSX.

### Reports Builder
- **Report Editor** (`/reports/editor`): drag-and-drop section composer with 6 section types — Heading, Text, Chart, Table, Metric Tile, Page Break.
- **5 chart types**: Bar, Line, Area, Pie, Grouped Bar — each connected to experience data.
- **Report Preview**: live preview rendered exactly as learners will see it.
- **Per-learner Report Card**: `/enrolments/:uuid/report-card` shows a learner's milestone completion tree and published reports.

### Teams Kanban Board
- **Teams screen** (`/teams`): drag-and-drop Kanban board with Unassigned + team columns.
- **Auto-assign**: balanced (equal distribution) or random algorithms; preview allocation before confirming.
- **Team CRUD**: create, rename, and delete teams inline on the board.

### SpecGuard Workspace Graph
- **`workspace.json` manifest**: registers all 12 Practera repos with their roles (consumer, provider, test, docs).
- **`contracts.json` graph**: 59 nodes and 50 edges mapping admin-app → graphql-api, admin-app → docs, admin-app → admin-php (iframe), admin-app → tusd (file upload) dependencies.
- **`specguard impact <spec>`**: BFS blast-radius analysis — which repos and specs are affected by a change to a given spec.
- **`specguard workspace status`**: cross-repo health dashboard showing spec coverage and drift status per repo.
- **`specguard workspace drift`**: runs `specguard drift` in all repos affected by uncommitted changes, ensuring contract consumers stay in sync.
- **New MCP tools**: `specguard_contracts`, `specguard_impact`, `specguard_workspace_status`, `specguard_workspace_drift`.

## 📄 Documentation

- New **Admin Platform** section in the Support Center ([docs/admin-platform/](https://support.practera.com/admin-platform/)) with 25+ pages covering Getting Started, Dashboard, Experiences, Institutions, Users & Enrolments, Deliver (Feedback, Chat, Reports, Progress), Setup (Designer, Calendar, Media Library), and Expert (Triggers, Badges).
- **28 Living Specs** in `practera-admin-app/specs/` and **10 Living Specs** in `practera-graphql-api/specs/` — the single source of truth for all admin-app functionality.
- Full cross-repo traceability via `practera/.specguard/contracts.json`.

## 🔧 Technical Changes

- `practera-admin-app`: new React/Vite service added to Docker Compose stack; served at `admin.practera.local`.
- `practera-nginx`: updated to route `admin.practera.local` → admin-app (port 4400) and `legacy.practera.local` → CakePHP admin (port 80).
- `practera-admin` (CakePHP): added `?iframe=1` detection in `header.ctp` — hides legacy nav when embedded as iframe.
- `practera-graphql-api`: new dashboard statistics, design project, file store, metrics, and skills growth queries serving the new admin screens.
- `specguard`: new workspace graph commands (`contracts`, `impact`, `workspace init/status/drift`) and 4 new MCP tools.
- `practera-devops-center`: `practera-admin-app` added to service selector (Frontend group); URL mappings updated in TUI.

- Fixed AuthProvider resolving token synchronously to eliminate the unauthenticated flash on protected routes.

- Fixed institution dropdown missing CS admin items (CS Manager, Super Badges, Billing) when role is `cs_admin`.
